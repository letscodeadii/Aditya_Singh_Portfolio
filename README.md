## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/letscodeadii/portfolio.git
```

### Navigate to the Project

```bash
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

### Build for Production

```bash
npm run build
```
