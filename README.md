# Aditya Singh Portfolio 🌐

A modern, responsive personal portfolio website showcasing my skills, projects, education, certifications, and experience as a Full Stack Developer. The website serves as a central hub for recruiters, collaborators, and developers to explore my work and connect with me.

🔗 **Live Website:** https://aditya-singh-portfolio-omega.vercel.app/

---

## 🚀 Features

- Responsive and mobile-friendly design
- Modern UI with smooth animations
- About Me section
- Technical Skills showcase
- Featured Projects
- Education & Certifications
- Resume download
- Contact section
- Social media links
- Fast deployment using Vercel

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/portfolio.git
```

Navigate to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Build for production:

```bash
npm run build
```
